# Sunset District

Прототип «GTA-like» открытого мира в браузере: процедурно генерируемый город,
третье лицо, физика персонажа на Rapier и камера-орбита.

Никаких внешних ассетов: вся геометрия, текстуры и окружение генерируются кодом.

## Стек

| Слой | Пакет |
|---|---|
| Сборка | Vite 8 + React 19 + TypeScript |
| 3D | Three.js через React Three Fiber 9 + drei 10 |
| Физика | @react-three/rapier 2 (Rapier 3D, WASM) |
| Состояние | Zustand 5 |

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5178
npm run build      # tsc --noEmit && vite build
npm run preview    # прод-сборка локально
```

## Деплой на GitHub Pages

Публикация идёт через GitHub Actions — сервером выступает сам GitHub.
Workflow `.github/workflows/deploy-pages.yml` на каждом пуше в `main`:

1. `npm ci` + `npm run build` с `VITE_BASE=/g/` (project-site живёт по `/g/`),
2. `actions/configure-pages` включает Pages, если он ещё не был включён,
3. `actions/upload-pages-artifact` → `actions/deploy-pages` публикует `dist`.

Адрес сайта: <https://bjpfv12-ui.github.io/g/>

Локально повторить прод-сборку с тем же base:

```bash
VITE_BASE=/g/ npm run build   # PowerShell: $env:VITE_BASE='/g/'
npx vite preview
```

## Автокоммит

Каждая серия правок сама превращается в коммит и уезжает в `main` (а значит,
передеплоивается на Pages). Сторож — `scripts/autocommit.mjs`:

| Что | Как |
|---|---|
| Срабатывание | 10 секунд тишины в рабочей папке, затем коммит |
| Состав коммита | все незакоммиченные изменения (`git add -A`) |
| Сообщение | `авто: <область> — <файлы>`, область выводится по путям (`компоненты`, `мир`, `код`, `деплой`) |
| Push | в `origin/main`; при конфликте — `pull --rebase` и повтор |
| Защита | пропускает цикл во время merge/rebase и при блокировке индекса |
| Лог | `.git/autocommit.log`, PID — `.git/autocommit.pid` |

Сторож запускается задачей Windows `SunsetDistrictAutoCommit` при входе в систему.

```bash
powershell -ExecutionPolicy Bypass -File scripts\install-autocommit.ps1   # поставить и запустить
powershell -ExecutionPolicy Bypass -File scripts\stop-autocommit.ps1     # остановить
node scripts/autocommit.mjs --once                                       # один прогон вручную
node scripts/autocommit.mjs                                               # работать в текущем окне
```

Переменные окружения: `AUTOCOMMIT_QUIET_MS` (тихий период, мс),
`AUTOCOMMIT_PUSH=0` — только коммиты, без push.

## Управление

| Действие | Клавиши |
|---|---|
| Ходьба | `W` — вперёд, `S` — назад (по курсу персонажа) |
| Поворот | `A` / `D` — доворачивают персонажа, камера встаёт за спину |
| Прицел | мышь — поворачивает камеру, корпус доворачивается следом |
| Спринт | `Shift` (удержание) |
| Прыжок | `Space` |
| Открыть/закрыть дверь | `E` |
| Камера | мышь (после захвата курсора) |
| Пауза / отпустить мышь | `Esc` |

Клавиши читаются по `event.code`, поэтому работают и в кириллической раскладке.

## Как устроен город

1. **Сетка.** `blocks × blocks` кварталов (`7 × 7`), между ними — дороги шириной 16 м.
   Шаг сетки = `blockSize + roadWidth` = 80 м, полный город ≈ 576 м.
2. **Кварталы.** Каждый квартал — плита-тротуар высотой 0,15 м. Внутри участок
   делится бинарным сплитом на лоты, в лоте стоит здание с зазором от соседей.
3. **Высота.** Рассчитывается от удалённости до центра: в деловом центре — до 86 м,
   на окраине — 9–18 м. Из этого растёт скайлайн.
4. **Окна.** Считаются по фасадам с этажностью 3,6 м; 42 % окон «горят» —
   на закате это и создаёт ощущение живого города.
5. **Дороги.** Асфальт с процедурной текстурой, двойная жёлтая линия по центру,
   белые краевые линии, разметка не заходит в перекрёстки.
6. **Дальний план.** Кольцо из 150 силуэтов за границей города — город читается
   большим, а не «одним экраном».

## Как устроен персонаж

- Динамическое тело Rapier с заблокированными вращениями и CCD.
- Ход идёт **по собственному курсу персонажа**, а не по курсу камеры: в повороте
  персонаж заходит в дугу, а камера остаётся за спиной.
- Корпус доворачивается к прицелу с ограничением скорости (6,5 рад/с) — модель
  никогда не проворачивается рывком на пол-оборота.
- `A`/`D` доворачивают камеру вокруг персонажа (1,9 рад/с ≈ 109°/с), корпус
  доворачивается следом с задержкой в несколько градусов.
- Ускорение через `THREE.MathUtils.damp` — нет мгновенных остановок.
- Спринт на Shift ровно в **1,8 раза** быстрее ходьбы (5,4 → 9,72 м/с),
  в воздухе управление вялое.
- Прыжок — вертикальный импульс 8,8 м/с, гравитация −22 м/с², есть «coyote time».
- Автоматический шаг через бордюр: луч ищет ступеньку **заранее**, за 0,7 м, и
  персонаж наезжает на неё без остановки. Прыжок срабатывает не чаще раза в
  0,45 с и только на ступеньки высотой 0,04–0,45 м.
- Опора определяется «липким» лучом: ещё 0,1 с после касания персонаж считается
  на земле — скорость хода не пульсирует на стыках плиток.
- Модель собран из примитивов (капсула-торс, сфера-голова, руки, ноги, рюкзак),
  шаг анимируется синусоидой от скорости: длина цикла 2 м, руки в противофазе
  с ногами, корпус подпрыгивает на каждом шаге.
- **Крен корпуса в повороте**: скорость поворота персонажа задаёт наклон
  до 12,6° в сторону заноса, на спринте корпус дополнительно наклоняется вперёд.

## Камера

- Орбита вокруг игрока, мышь меняет `yaw`/`pitch`.
- Сглаживание через экспоненциальный lerp — камера «весит», не дёргается.
- Пять лучей от игрока в сторону камеры (центр и четыре смещения): при попадании
  в стену камера подтягивается ближе и не ныряет в углы.
- Минимальная дистанция 1,4 м и нижняя граница высоты — камера не уходит в
  землю и не застревает внутри игрока.
- Смещение вбок — вид «через плечо», как в GTA.
- На спринте плавно расширяется поле зрения (66° → 74°).

## Машины

`ParkedCars.tsx` — припаркованные машины стали полноценными физическими телами:
у каждой свой `RigidBody` (динамический, вращение только вокруг Y) и свой кузов
с `CuboidCollider`.

Сейчас это **статичные объекты мира**: сесть в машину и ездить на ней нельзя,
игрок может только задеть кузов — машина отталкивается как обычное твёрдое тело.
Прежняя система вождения (посадка по `F`, газ/тормоз/руль, камера за рулём,
спидометр машины) удалена целиком и будет заменена новой по ТЗ.

Асфальт скользкий (`friction 0.15`) — так припаркованные машины легко сдвинуть
с места, а у самих машин трение среднее (`0.6`).

Спидометр в HUD показывает скорость игрока из `linvel()` в километрах в час.

## Графика в духе San Andreas

| Элемент | Реализация |
|---|---|
| Пальмы | Конический ствол (цилиндр 0.68→1) + 6 длинных поникающих листьев; вдоль тротуаров, по 3–6 штук на сторону квартала |
| Фонари | Тонкий цилиндрический столб 7,2 м + сферический плафон со свечением |
| Машины | Корпус + салон + 4 колеса-цилиндра (у едущих машин колеса крутятся вместе с кузовом) |
| Окна | Тёмно-синие решётки по фасадам, ~30 % окон «горят» тёплым светом |
| Крыши | Парапет, вентиляция, антенны — отдельными инстансами |
| Небо | `drei/Sky` с солнцем на 45°, плюс 48 белых полупрозрачных плит-облаков, дрейфующих по ветру над городом |
| Свет | Тёплое солнце `#fff4e6` под 45°, холодный ambient `#b0c4de`, карта теней 2048² |
| Туман | `#c9d6df`, near 50 / far 300 — как в Los Santos, дальний город уходит в дымку |

Дополнительно: небо снимается в кубическую карту (`Environment`), чтобы стекло и
кузова отражали небо, и стоит постобработка (`PostFX`): экспозиция кадра в
композиторе, bloom на солнце и окнах, лёгкая насыщенность, ACES-тонмаппинг,
виньетка по краям кадра и плёночное зерно — как на PS2-версии Los Santos.

## Живой город

**Транспорт.** 34 машины едут по сетке улиц: держатся правой полосы (смещение 4 м
от осевой), на перекрёстках с вероятностью 34 % поворачивают, выехав за границу
города — переспавниваются в 140 м от игрока, чтобы не «моргать» на глазах.
Если игрок оказался прямо по курсу, машина тормозит.

**Пешеходы.** 30 NPC идут по кольцу тротуара вокруг квартала, со случайным
смещением внутри полосы и покачиванием при ходьбе. Переулки и площади остаются
пустыми — это прототип, а не толпа.

**Двери.** До 26 зданий получают вход: проём с простенками, перемычкой, вывеской
и тёплым светом внутри. Подойдя ближе 4,2 м, игрок видит подсказку «E — открыть
дверь»; створка плавно (пружина, 6 1/с) отходит в сторону.

**Мини-карта.** Отдельный canvas 190×190 в углу HUD: кварталы, осевые линии
улиц, стрелка игрока по курсу, оранжевые точки машин и бирюзовые точки
пешеходов. Обновляется 15 раз в секунду.

## Производительность

- Повторяющиеся объекты (здания, окна, деревья, фонари) — `InstancedMesh`
  с per-instance цветом, всё в 4 чанка для frustum culling.
- Окна — `MeshBasicMaterial`: «светящиеся» окна не зависят от освещения и не бьют
  по карте теней.
- Коллайдеры города — статические кубы в одном `RigidBody`.
- Припаркованные машины вынесены из инстансинга: у каждой своё тело и два меша
  (кузов с кабиной и колёса) — так их можно расталкивать и позже посадить
  в них игрока.
- Тени: одна направленная лампа едет за игроком, ортокамера 170 × 170 м.

## Проверка

```bash
node scripts/verify.mjs   # headless Chrome: скриншоты, телеметрия, ошибки консоли
node scripts/clouds.mjs   # статистика облаков + снимки со свободной камеры
node scripts/motion.mjs   # профиль скорости хода и реакция на поворот
```

`scripts/motion.mjs` меряет ход по цифрам: разгон, разброс скорости на ровном
участке, число вертикальных прыжков, остановки и скорость доворота корпуса.
Запускается по dev-серверу (`npm run dev`), потому что нужны dev-хуки
`__playerState` и `__cameraStore`. Переменная `GPU=1` включает настоящую
видеокарту вместо SwiftShader — без неё headless выдаёт ~2 fps и замер бессмыслен.

Скрипт открывает игру в Chrome, снимает кадры в `verify/`, имитирует `W` / `Shift+W` /
`Space` / `A` и печатает координаты и скорость персонажа.

`scripts/clouds.mjs` использует dev-хук `__freeCam` (`CameraFollow`): пока он задан,
камера рига не управляется мышью, а стоит там, куда её поставил скрипт. Так снимают
облака с высоты — игровая орбитальная камера в небо почти не задирается.
